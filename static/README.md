# static/

Put site assets here.

- `resume.pdf` — linked from the "Résumé" button in the hero on index.html
- `img/` — project and portrait images

To use an image for a project, add an `image` field to its entry in `data.js`:

    image: "static/img/buzzmatch.png"

For the hero portrait, add a `background-image` to `.hero__photo-inner` in index.html.
